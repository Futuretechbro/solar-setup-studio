# Solar Setup Studio

build a landing page that has these features: 
1. a solar setup calculator
2. a carousel of brands which we work with
3. free tools on the site section: a solar setup calculator, a quotation maker and invoice maker
4. our whatsapp bot on its uses: all three tools are accessible via the bot. the calculator,quote and invoice
5. how it works
6. why asks {our brand name}
7. solar first, more hands later. list other services that we plan to link users with in the future

note: you don't have to build them in the order above. use your intelligence to decide the order
